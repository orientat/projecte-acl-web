# Corrector ACL — interfície web

Interfície estàtica per a registrar respostes i resumir resultats de proves ACL. Qualsevol persona pot obrir esta pàgina.

## Privacitat

- Este repositori i el web publicat no inclouen claus de resposta, barems, llistes d'alumnat ni resultats.
- La docent selecciona al seu dispositiu un fitxer ACL privat. El navegador el llig localment i no l'envia a GitHub ni a cap servidor.
- Els grups i les respostes es guarden en l'emmagatzematge local del navegador. Exporta una còpia JSON per a traslladar-los a un altre dispositiu.

## Ús

Obri [el web publicat](https://orientat.github.io/projecte-acl-web/), carrega el fitxer de configuració ACL des del teu dispositiu, crea el grup i registra cada resposta o omissió. El resum de grup es pot consultar amb gràfics i imprimir o guardar en PDF, sense mostrar noms d'alumnat. El CSV és la taula de dades per a Excel.

L'eina és un suport docent. Cal validar les claus, els barems i els criteris amb les fonts autoritzades abans d'usar els resultats.

## Publicació

El workflow publica únicament els fitxers index.html, app.js i styles.css. No afegisques claus, barems ni fitxers de l'alumnat a este repositori.
